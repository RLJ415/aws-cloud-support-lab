# AWS Cloud Support Lab

## Overview

This project is an interactive AWS Cloud Support dashboard built with HTML, CSS, and JavaScript. It simulates how a Cloud Support Engineer or Cloud Operations team can monitor, manage, and update service incidents from a single dashboard.

---

## Features

- Create new AWS incidents
- View incident details
- Update incident status
- Delete incidents
- Search incidents by AWS service
- Filter by service
- Filter by status
- Combined search + service + status filtering
- Sort incidents alphabetically by AWS service
- Dynamic analytics dashboard
- Incidents by AWS service
- Recent activity log
- Automatic priority assignment (P1, P2, P3)
- Sequential incident ID generation
- Input validation
- Automatic severity reset after incident creation
